FAQ

Short answers. The README in the repository is the longer source.

What is Casmos?

Casmos is an unofficial, open-source Telegram client for Mac. It is based on the Telegram for macOS source. Chat, themes, and accounts work like a normal Mac messenger, with extra local privacy toggles.

Is Casmos made by Telegram?

No. It is not affiliated with Telegram FZ-LLC and it does not use the official paper-plane logo.

Does Casmos make me anonymous?

No. Casmos is a low-leak client. Traffic still goes to Telegram's network. Privacy toggles hide things on this Mac. They do not hide you on the wire.

What are chat groups?

Local tabs on the chat list. All shows every chat. A group shows the chats you dragged onto that tab, or added with Add to Group. Ungrouped shows chats that are not in a group. They stay on this Mac and are not Telegram folders. Deleting a group does not delete the chats.

What does hide mean?

Hide means the local interface stops showing something. Hide Stories takes the stories strip and avatar rings off the chat list. Hide Phone and Username takes your number and @username off your own profile and Settings on this Mac. Message Filter hides matching incoming text in the chat and the list preview. Keep Deleted Messages (off by default) keeps chats this Mac already has after someone else deletes them; it does not fetch messages that never arrived. None of those toggles change Telegram's servers.

How do I install it?

Build it from the public repository. See github.com/Thecosmiccat/Casmos and the INSTALL file there. You need Xcode and your own Telegram API credentials.

Why do I need my own API credentials?

Casmos does not ship live api_id or api_hash values. Get them from my.telegram.org and put them in ~/Library/Application Support/Casmos/api-credentials.json with mode 600. Do not commit live keys.

What is the license?

GNU General Public License, version 2.0. Upstream Telegram for macOS source stays under that license. Publish your changes if the GPL requires it.

Are iOS, Linux, or Windows available?

No. Those are marked Coming soon. They are not downloadable. Extra app icons are also Coming soon. The bundled Casmos icon is the one that ships.

What is panic passcode?

An account passcode locks that account. Hide This Account drops it from switchers until you type that passcode. Panic hides the accounts you include for this session. Hide This Account survives quit. Logout on Panic also signs those accounts out, and that option is off by default.

Does Casmos update itself?

No. Official Sparkle and App Center update endpoints are blank. Casmos does not ship in-app updates from osx.telegram.org or App Center.

Where do I get help?

Open an issue on github.com/Thecosmiccat/Casmos/issues.
