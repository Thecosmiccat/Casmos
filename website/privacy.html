Privacy Policy

Effective 17 September 2026.

Who this covers

This policy covers the Casmos marketing website and the Casmos macOS app published at github.com/Thecosmiccat/Casmos. Casmos is an unofficial, open-source Telegram client. It is not affiliated with Telegram FZ-LLC.

This website

These pages are static files. The site does not create accounts, does not run a first-party analytics product, and does not ask you for a name, email, or password.

The Casmos app

Casmos is a Telegram client. When you sign in and send or receive messages, that traffic goes to Telegram's network the same way it would in other Telegram clients. Casmos does not operate Telegram's servers and cannot make you anonymous on that network.

You supply your own Telegram API credentials. The running app reads them from a local file at ~/Library/Application Support/Casmos/api-credentials.json. That file is not in the public git repository.

What stays on your Mac

Casmos Settings store casmos.pref.* keys on this Mac. Privacy toggles hide things in the local interface. They do not delete data on Telegram's servers and they do not hide you from the network.

  • Hide Stories, Hide Phone and Username, Confirm External Links, Lock on Sleep, and Hide Content in App Switcher default on for a fresh install.
  • Message Filter hides matching incoming text in the chat and list preview on this Mac. It does not delete messages.
  • Keep Deleted Messages is off by default. When on, this Mac keeps already-downloaded chats after someone else deletes them and labels them Deleted. It does not recover messages that never reached this Mac.
  • Chat streaks, compact chat list, monochrome folders, and local profile banners stay on this Mac.
  • Chat groups are local tabs on the chat list. They are stored on this Mac and are not synced as Telegram folders.
  • An account passcode is stored as a PBKDF2 hash in the Keychain with WhenUnlockedThisDeviceOnly.
  • Hide This Account and panic passcode hide accounts in the local UI. Logout on Panic is off by default.
  • Verbose Logging is off by default. Casmos logs are not supposed to include message bodies, phone numbers, or api_hash.

Optional translators

Translate Messages can use System, Extra (web fallback), Yandex (local), or DeepL. A DeepL key, if you set one, is stored in local preferences. Exporting Casmos preferences to JSON can include that key if it is set. Turn translators off if you do not want text sent to those engines.

Children

The website is general information about a messenger client. It is not directed at children under 13.
