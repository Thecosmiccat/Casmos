# Casmos roadmap

## P0 (this tree)

- Casmos identity: display name, bundle IDs, icon that is not the official paper plane
- API credentials as `CASMOS_PLACEHOLDER_*` only
- Casmos Settings shell: General, Appearance, Chat, Translator, Passcode, Experimental (`casmos.pref.*` stubs)
- Modular `packages/Casmos`
- Official Sparkle and App Center update endpoints blanked
- Mac Xcode build notes in INSTALL.md

## P1 (later — not implemented here)

- Multi-engine translator
- Sticker size
- Pause video when the app is in the background

These P1 items have preference stubs in Casmos Settings so keys exist; they do not change playback, stickers, or translation yet.
